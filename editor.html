ansatz
Body text is Markdown. Wrap content that belongs to one post section in ::: section [left|right|full] … ::: (omit the keyword for a right-aligned card, the default). Inside a right/left section, an optional floating card goes in its own ::: card … ::: block with key: value lines.
::: section
starts a two-column section with a right-aligned card (default, matches blog.html's un-classed section)
::: section left
same, but the card floats on the left
::: section full
full-width text column, no card — for body copy that shouldn't wrap around anything
::: card … :::
image:, label:, heading: and description: lines (any may be omitted)
## Heading
a large section heading (span.big), e.g. "Left Column Content"
```lang ... ```
a syntax-highlighted code block
![alt](url)
a full-width inline image with no caption
![alt](url "Caption")
a full-width image with a caption only
![alt](url "Title|Caption")
a full-width image with a bold title followed by a caption
::: desmos … :::
an embedded, interactive Desmos graph or geometry construction (not an iframe — uses Desmos' calculator API). url: loads a saved graph/construction by its Desmos share link (desmos.com/calculator/<id> or desmos.com/geometry/<id>, detected automatically) — colors, bounds, sliders, and labels come along automatically, nothing to retype. Optional height: (px, default 400) and width: lines control the embed's pixel size (omit width for full-width); expressions: false hides the expressions list (default shown) — for a geometry construction this also hides the construction toolbar (point/segment/circle/etc.) and the undo/redo buttons, for a clean read-only display. Any other line is an extra LaTeX expression added on top, e.g. y=x^2 — useful even without a url:
::: shader … :::
a full-width, real-time WebGL2 visual — Shadertoy-style GLSL ES 3.00. Give it a -- buffer -- section (optional) and/or an -- image -- section, each with its own mainImage(out vec4 fragColor, in vec2 fragCoord); both can sample the buffer's previous frame via iChannel0, and iResolution/iTime/iFrame are implicit, same as Shadertoy — don't declare any of them yourself. Optional height: (px, default 400) and width: lines (before either section) control the embed's size (omit width for full-width); optional title: and caption: lines wrap it in a captioned <figure>, styled the same as an image figure's (either may be omitted; give just one for a caption with no bold lead-in, or just the other for a bold title alone)
$inline$ / $$block$$
LaTeX, rendered with KaTeX. A multi-line $$ … $$ block containing & is auto-wrapped in an aligned environment, so & marks the alignment column and \\ breaks the line, e.g. a &= b + c \\ &= d (skip the auto-wrap by writing your own \begin{...} environment)
**bold**, *italic*, `code`, [text](url)
standard inline Markdown
